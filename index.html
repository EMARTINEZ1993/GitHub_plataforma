02 — Git vs GitHub

Antes de empezar, es importante entender que Git y GitHub no son lo mismo.

commit Git

Es un programa que se instala en tu computador. Sirve para guardar versiones de tus archivos mientras trabajas.

cloud GitHub

Es un sitio web donde puedes publicar en internet los proyectos que guardaste con Git.

En resumen: Git guarda versiones en tu computador y GitHub las publica en internet. Se usan juntos, pero son herramientas distintas.

05 — Configurar Git

Git necesita saber quién realiza los commits. Para eso se configuran el nombre y el correo del autor.

info

Importante

user.name y user.email no son las credenciales de GitHub ni sirven para iniciar sesión. Solamente indican quién aparece como autor de los commits.

Nota: user.name no es tu nombre de usuario de Git ni de GitHub. Es solo el nombre que quedará registrado como autor de cada commit. Puedes escribir tu nombre real (por ejemplo "Ana Pérez") o el que prefieras que aparezca.
